# RQ6: site data vs public data only, per architecture (tile mode, the same 47 patients)

Written by rq6_report.py. Headline: per-patient Dice = mean of the patient's slide Dice. gap = site CV minus all-public, per patient (positive = our own patients help); in brackets: 95% bootstrap CI over patients, and the number of patients where site CV is better / worse. A gap below 0.03 between single runs is a tie.

Training data differ by design: the site-CV fold models train on 35-36 of our patients and are tested on the held-out 9-10; the all-public model trains on SICAPv2 + Karolinska + Radboud (equal tile draws, none of ours) and is tested on all 47. Each pair uses the same architecture, recipe, epochs and seed. Machines: see the summary of each model (the U-Net baseline ran on the 4090, the others on the H100 server, folds on GPU 1 or on the shared GPU 0; fold-0 machine difference about +0.016).
